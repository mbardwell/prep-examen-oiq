# Préparation à l'examen professionnel de l'OIQ

Simulation d'examen à choix multiples pour l'examen professionnel de l'Ordre des ingénieurs du Québec : une banque de 200 questions (50 par thème) qui affiche 25 questions par onglet. Le bouton **Nouvelle série** tire 25 autres questions au hasard.

Site statique (un seul `index.html` et le dossier `img/`), publié avec GitHub Pages.

Outil de révision personnelle, non officiel. Vérifiez toujours dans le guide d'étude de l'OIQ et dans les textes de loi.
